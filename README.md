# Muhurat Quant Screener & Claude AI Options Hub
### Finwurl Enterprises Private Limited • Powered by FinURL

High-performance institutional quant stock screener and live options intelligence radar for Indian Equity & Derivatives markets (NSE / NIFTY 200).

---

## 🌟 Key Features
- **Muhurat Home Cockpit**:
  - Central Pivot Range (CPR) Engine with TC, Pivot, BC, R1-R3, S1-S3, and Camarilla H4/L3 levels.
  - Multi-Index Radar: NIFTY 50, BANK NIFTY, FIN NIFTY, MIDCAP NIFTY, NIFTY NEXT 50, INDIA VIX.
  - Live NIFTY Option Chain Matrix: Interactive strike ladder, Open Interest (OI) bars, Put-Call Ratio (PCR), Max Pain, and ATM indicators.
- **Claude AI Options Hub**:
  - Real-time Buy/Sell trade setups across all 6 indices with listed timestamps, target levels, stop-loss, risk-reward ratios, and conviction scores.
- **Full Market & Sector Heatmap**:
  - Fullscreen treemap visualization with breadth ratios (Advances/Declines).
  - Multi-metric view switchers: % Price Change, OI Change %, PCR, IVP, Bid/Ask Ratio.
- **Quant Algorithmic Models**:
  - Muhurat Elite Engine (3m)
  - Muhurat Elite Pro Engine (6m)
  - Muhurat Pulse Model (RVOL & HyperFlow™)
  - Muhurat Flow Model (Institutional Whale Sweeps)
- **Live Broker Integration**:
  - Seamless real-time data streaming and order routing via Fyers API v3.
